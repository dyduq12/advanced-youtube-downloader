BAIXADOR DE VÍDEOS PRO - v1.0
ADVANCED VIDEO DOWNLOADER - v1.0

[PORTUGUÊS]
INSTRUÇÕES DE INSTALAÇÃO:
1. Extraia a pasta inteira para o seu computador.
2. ATENÇÃO: Nunca exclua nem mova a pasta "data/". Os arquivos internos são protegidos.
3. Dê dois cliques no arquivo "Instalar.bat" (ele vai pedir permissão de Administrador automaticamente).
4. O programa vai copiar o coração do sistema para o Windows e gerar o atalho com o ícone no seu Desktop.
5. Inicie o programa pelo atalho gerado na Área de Trabalho!

ONDE MEUS VÍDEOS SÃO SALVOS?
Os vídeos e áudios baixados são salvos nativamente na sua pasta padrão de Vídeos do Windows.
Caminho exato: %USERPROFILE%\Videos\Downloads

DESINSTALAÇÃO COMPLETA:
Dê dois cliques em "Desinstalador.bat". Ele limpará os arquivos temporários, o atalho, e se auto-destruirá limpando a pasta do instalador.

-----------------------------------------

[ENGLISH]
INSTALLATION INSTRUCTIONS:
1. Extract the entire folder to your computer.
2. WARNING: Never delete or move the "data/" folder. Its internal files are protected.
3. Double-click the "Instalar.bat" file (it will automatically ask for Administrator permission).
4. The program will copy the core system to Windows and generate the shortcut with the custom icon on your Desktop.
5. Start the program using the generated shortcut!

WHERE ARE MY VIDEOS SAVED?
Downloaded videos and audio are natively saved to your default Windows Videos folder.
Exact path: %USERPROFILE%\Videos\Downloads

COMPLETE UNINSTALLATION:
Double-click "Desinstalador.bat". It will clean temp files, the shortcut, and self-destruct to wipe the installer folder.
